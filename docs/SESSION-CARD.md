# Persistent session control

Journey: a lifter starts or resumes a workout, identifies the active exercise, logs sets, occasionally checks session elapsed time and ends deliberately. They can scroll through a long session without losing Finish. If the timer distracts them, Hide elapsed time collapses that information while Finish remains strong. Show elapsed time restores it, and the preference survives reload when browser preference storage is available. Finishing still opens the existing confirmation; Keep logging restores focus to the same Finish control. No automatic completion or new workout data schema.

Hierarchy: exact exercise and Log are the task focus. A small sticky white session card owns duration and Finish; Finish is filled charcoal, distinct from the vermilion Log action. Saved status remains visible in the top navigation. Secondary exercise setup remains collapsed. Inactive movements use a larger tappable card instead of another action label; accessible button names and focus remain native.

Elapsed time is wall-clock time since the stored workout startedAt, including time away/background. It is not measured active lifting time. It is derived on render/tick, does not write per second, and catches up on page visibility. Hiding the timer never pauses the session. Invalid/future timestamps clamp to zero; hours display correctly. The card respects safe area and finish confirmation scroll offset. Test expanded/collapsed, reload, scrolling, long sessions, tick, confirmation recovery and unchanged actuals.

Delivered: `SessionCard.tsx` is a reusable sticky session control. Expanded state shows a subordinate18px elapsed clock and saved-set count, a44px hide control and a48px charcoal Finish action. Compact state keeps only a restore-clock icon and Finish. The redundant draft ordinal is visually removed because Log set n already names the set; numeric fields retain full accessible labels. Timing derives from saved startedAt, with no per-second IndexedDB writes. The local preference is a separate best-effort UI setting.
